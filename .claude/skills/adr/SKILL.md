# ADR

1. Copy `docs/adr/0000-template.md` to `docs/adr/NNNN-<slug>.md` with the next number.
2. Fill context, options with trade-offs, decision, consequences.
3. Status: proposed, then accepted after human approval.
4. Never edit an accepted ADR. Supersede it with a new one.
