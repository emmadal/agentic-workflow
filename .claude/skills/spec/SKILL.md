# Spec

Produce `docs/specs/<slug>.md` with:

1. **Problem**: one paragraph.
2. **Goals / non-goals**.
3. **Acceptance criteria**: testable bullets.
4. **Edge cases and risks**.
5. **Open questions**.

Ask the user to resolve open questions before moving to `/plan`.
